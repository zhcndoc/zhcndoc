## 看出草稿缺了什么

> 准备好后运行脚本，会生成索引。看到结果就可以继续。更多说明请参考文档。

读者可能从搜索直接进入这段，需要知道工具在哪个目录运行、输入是什么、输出如何核对。可先用[读者与范围](/docs/start/audience)确定一个目标。这里的目标是在已安装 Node.js 的本地环境中，输出一条示例文档记录并验证标题。

## 写出可复制的操作

用 `node --input-type=module` 运行下列脚本。示例适用于支持 heredoc 的 Shell。脚本用一个内存数组模拟索引，输出第一条文档的标题。

```bash
node --input-type=module <<'NODE'
const index = [{ id: 'search-settings', title: '配置搜索' }]
console.log(index[0].title)
NODE
```

执行后，终端应显示“配置搜索”。将第一条记录的 `title` 改成“生成索引”并重跑，可验证输出来自输入数组。需要从多条记录选择子集时，可以按[实用配方](/docs/examples/recipes)的步骤处理。
