## 中西文间距

中文与相邻的拉丁字母或阿拉伯数字之间留一个半角空格。中文标点两侧紧排，品牌和专有名称保留官方写法。这个空格约定用于正文和标题，代码、命令、URL 和标识符沿用原有语法。

这个约定参考了[中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines)的录入方式。W3C 的《[中文排版需求](https://www.w3.org/TR/clreq/#mixed_text_composition_in_horizontal_writing_mode)》进一步介绍了横排文字的间距。

| 场景               | 写法                             |
| ------------------ | -------------------------------- |
| 中文夹用西文       | 使用 GitHub 提交改动。           |
| 中文夹用数字       | 构建生成 3 个文件。              |
| 中文标点紧邻词语   | 模块支持 JSON、YAML 和 TOML。    |
| 行内代码与中文混排 | 修改 `nuxt.config.ts` 中的配置。 |

## 标点与引号

简体中文句子使用中文标点。并列的词语用顿号，完整陈述以句号收尾。引用界面文字用中文双引号，内层引用用中文单引号。正文中的补充说明使用中文圆括号，省略号写作“……”，破折号写作“——”。

英文原句、机器输出和代码标点按原样呈现。链接的括号、反引号和列表标记采用 Markdown 语法。长段落交给浏览器按可用宽度换行。在窄屏上按[中文标点的换行规则](https://www.w3.org/TR/clreq/#prohibition_rules_for_line_start_end)检查逗号、句号和引号的位置。

## 数字、单位和日期

正文中的数量、版本和测量值使用半角数字。量值和单位之间留一个半角空格，例如 250 ms、64 MiB 和 25 °C。百分号和角度符号紧跟数字，例如 25% 和 90°。

正文日期写作“2026 年 11 月 20 日”，配置或 API 示例使用接口规定的格式，例如 `2026-11-20`。时间涉及跨时区使用时，注明时区。范围写出边界与单位，例如“从 10 ms 到 20 ms”，并在需要时明确边界是否包含在内。

## 分步检查排版

1. 用[中西文混排规则](/docs/typography/mixed-text)检查链接、产品名和行内代码两侧的空格。
2. 按[中文标点用法](/docs/typography/punctuation)统一引号、点号和上下文中的原标点。
3. 在[数字、单位和时间](/docs/typography/numbers-and-units)中核对示例值、时区和边界。
4. 预览窄屏并复制代表性命令，验证正文换行和代码字符均符合预期。

对已经翻译的页面，可以逐段先查术语和技术含义，再检查排版。这样可以把对照原文时发现的含义变化和纯排版调整记录清楚。
