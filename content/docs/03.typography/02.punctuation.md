## 给标点明确的用途

中文正文使用简体中文常用标点。用句号结束完整陈述，用问号表达真实的问题，用逗号分隔句中的停顿。紧密并列的词语用顿号。几个并列内容各自较长时，可以拆成完整句子或按[列表规则](/docs/elements/lists-and-tables)分项。

| 标点或符号    | 用法                 | 示例                         |
| ------------- | -------------------- | ---------------------------- |
| 句号 `。`     | 结束完整陈述         | 保存配置后重新构建。         |
| 逗号 `，`     | 隔开条件、动作或结果 | 构建完成后，检查输出目录。   |
| 顿号 `、`     | 分隔并列的短词       | 核对标题、链接和示例。       |
| 圆括号 `（）` | 说明缩写或范围       | 服务端渲染（SSR）            |
| 书名号 `《》` | 标出规范或作品名     | 《中文排版需求》             |
| 省略号 `……`   | 标记实际省略的文字   | 界面持续显示“正在生成索引……” |

## 引用界面文字和嵌套原话

简体中文正文的外层引号用“”，内层用‘’。界面文字按实际显示引用，例如“打开‘搜索设置’”出现在更长的一段引用中。完整的中文引语保留其原有句末标点。只引用一个短语时，整句的标点跟随正文。

破折号写作“——”，可用于保留来源中已有的停顿或插入成分。对技术步骤，更明晰的方式是把原因、结果和限制写成独立句子。数值范围可以用“到”说明上下界。命令行参数里的连字符原样保留。

## 检查中西文交界和换行

中文句子使用中文标点，即使其中含有英文词语。英文原句、代码和终端输出保留原标点。例子中可以写“设置 `mode: 'local'` 后，重新启动服务”。中文标点与邻近文字紧排。更多例子可从[中西文混排](/docs/typography/mixed-text)查看。

预览窄屏时观察引号、括号和点号的落点，按 W3C 的[行首行尾禁则](https://www.w3.org/TR/clreq/#prohibition_rules_for_line_start_end)了解浏览器排版行为。让浏览器按可用宽度折行，正文中的有意分段使用正常空行。
